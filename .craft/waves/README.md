# Wave Archive

Wave directories are historical research and generated work packets. They are
valuable source material, but they are no longer the active operating surface.

Use active directories instead:

- OpenClaw work: `projects/openclaw/`
- Lobster work: `projects/lobster/`
- PR queue notes: `projects/prs/`
- Local tools: `tools/`

When a wave artifact becomes active work, promote a summary or the runnable
artifact into the appropriate active directory and leave the original wave in
place as provenance.
