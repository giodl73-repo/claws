# Pulse 16: API Stability Contract Tests

## Objective

Establish the API stability contract that governs the free/paid boundary. The curated re-export list in `@bic/claws-sdk` is the public API -- this pulse adds the machinery to enforce that contract: publint for packaging correctness, API diff against a committed baseline snapshot, integrity hash verification for tamper detection, and a CHANGELOG.md to document every public API change. This is the safety net that prevents accidental breaking changes from reaching consumers.

Per R1 review C5: semver is enforced mechanically, not by convention. Every release must pass publint + API diff + integrity check before publish is allowed.

## Deliverables

- [ ] `packages/@bic/claws-sdk/api-baseline.json` -- Committed snapshot of the public API surface: every exported symbol name, type signature, and module path. Generated by a script, committed to source control, diffed on every PR.
- [ ] `packages/@bic/claws-sdk/scripts/generate-api-baseline.ts` -- Script that introspects the package exports and produces api-baseline.json. Uses TypeScript compiler API to extract symbol names and signatures.
- [ ] `packages/@bic/claws-sdk/scripts/check-api-diff.ts` -- Script that compares current exports against api-baseline.json. Reports additions (minor bump), removals (major bump), and changes (major bump). Exits non-zero if removals or signature changes are detected without a version bump.
- [ ] `packages/@bic/claws-sdk/scripts/integrity-hash.ts` -- Generates SHA-512 integrity hash of the package tarball for pinning in @bic/claws-sdk. Outputs hash in `sha512-...` format compatible with npm integrity fields.
- [ ] `packages/@bic/claws-sdk/CHANGELOG.md` -- Initial changelog following Keep a Changelog format. Documents the 1.0.0 release with all public API symbols.
- [ ] `packages/@bic/claws-sdk/tests/api-contract.unit.test.ts` -- L0: api-baseline.json exists and is valid JSON (1 test), every symbol in baseline is currently exported (1 test), no symbol is exported that is not in baseline (1 test), publint reports zero errors (1 test), integrity hash is deterministic for same content (1 test), CHANGELOG.md has entry for current version (1 test)
- [ ] `packages/@bic/claws-sdk/tests/api-diff.integration.test.ts` -- L1: adding a new export is detected as minor change (1 test), removing an export is detected as breaking change (1 test), changing a type signature is detected as breaking change (1 test), api-baseline.json round-trips through generate script (1 test)
- [ ] `packages/@bic/claws-sdk/tests/publish-readiness.e2e.test.ts` -- L2: npm pack produces valid tarball that passes publint (1 test), integrity hash of tarball matches regenerated hash (1 test)

## Acceptance Criteria

- [ ] `publint` reports zero errors on `@bic/claws-sdk`
- [ ] API diff check passes against committed baseline
- [ ] Integrity hash is reproducible (same content = same hash)
- [ ] CHANGELOG.md exists and documents 1.0.0
- [ ] Removing a public symbol causes the API diff check to fail
- [ ] Adding a public symbol is detected but does not fail (minor change)
- [ ] `npm run build` exits 0
- [ ] `npx tsc --noEmit` exits 0
