# Security policy

Report suspected vulnerabilities privately before opening a public issue. Use
GitHub's **Security** tab after this repository is hosted. If that route is
unavailable or ownership is unclear, email `security@openclaw.ai`.

Include the affected revision, source type, harness, reproducible steps,
demonstrated impact, environment details, and suggested remediation. Do not
include live credentials, personal data, or customer content.

Useful reports identify a bypass of package integrity, archive extraction,
path safety, source-origin binding, consent, process execution, authentication,
or harness policy. OpenClaw runtime vulnerabilities follow the
[OpenClaw security policy](https://github.com/openclaw/openclaw/security/policy).
