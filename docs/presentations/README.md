# claws -- Presentations

Slide decks presenting the claws governance compiler to different audiences, each built with Marp using the claws-dark theme and exported to `.pptx`. The `guidance/` subdirectory contains expert review feedback and typesetter refinements used during deck production.

**Why claws** is the opening pitch: 5,198 skills, 138 CVEs, 824+ malicious, zero governance -- and one compiler that addresses both the skill quality problem and the security problem through the same compilation pipeline. **Security Model** targets CISOs, security architects, and red teams with compiled governance for AI agents -- not prompt engineering, not runtime prayers. **Compliance** covers regulatory evidence production (GDPR, CCPA, SOC2, HIPAA) through auditable compilation artifacts. **Fleet Operations** addresses IT operations and platform teams managing tens to hundreds of OC agent workspaces from one terminal with a single policy floor. **Maker** targets skill builders entering the governed-skills world: one framework, one compiler, one publish. **Technical Deep Dive** is for OC platform engineers and covers the compilation pipeline internals, IR design, artifact emission, and Gateway integration.
