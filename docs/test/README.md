# @bic/claws-test

The test harness package — accept-runner for manifest-driven
scenarios, doc-validation gate (17 diagnostic codes), and the
no-craftworks gate that prevents craftworks-internal residue from
shipping in claws artifacts.

## Two-letter code

**TX** — package primary. Sub-specs: **TXA** (accept-runner),
**TXD** (doc-validation), **TXN** (no-craftworks).

## Stability

- **Stability tier**: Alpha
- **Upstream target**: none (internal test harness)
