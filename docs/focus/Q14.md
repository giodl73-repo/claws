# Q12n: How does claws map to the 5,198 skill ecosystem?

**Priority**: High
**Status**: Open
**Owner**: giodl
**Resolves**: Which of the 30 OC skill categories does claws replace, complement, or enable; governance policy templates per category; OBO boundary mapping across communication/productivity/commerce skills; risk classification defaults for each skill type
**Blocks**: Default policy templates, skill-kit governance annotations, ClawHub integration
**Experiments**: 10 (one per logical unit)

---

## Question

The awesome-openclaw-skills repo catalogs 5,198 skills across 30 categories. These group
into 10 logical units. For each unit, TWO questions:

1. **Governance**: What risk classification (R1-R5), OBO boundaries, data labels, and
   policy rules apply? What existing governance skills does claws replace?
2. **Maker**: How does claws help developers CREATE better skills in this category?
   What @claws/* libraries add value? What templates/scaffolds should claws provide?

## Answer

claws maps to the 5,198 skill ecosystem through TWO complementary faces:

**Governance face**: claws provides risk classification defaults (R1-R5), OBO boundary enforcement,
data sensitivity labels (PHI/PII/FINANCIAL/etc.), and policy templates for each of the 10 skill
units. The ecosystem has 66 OBO-crossing skills in communication alone, 322 browser skills with
100% injection risk surface, 111 R5 TRANSACT skills in commerce, and 43 physical-world IoT skills.
Without governance, agents can send email, spend money, control ovens, and push to production
without confirmation.

**Maker face**: claws provides 11 @claws/* libraries that help skill authors BUILD better skills.
`@claws/security` for input sanitization, `@claws/budget` for spending controls, `@claws/data`
for typed data access with sensitivity labels, `@claws/obo` for On-Behalf-Of annotations with
approval flows, `@claws/audit` for change logging, `@claws/report` for document generation,
`@claws/iot` for physical safety limits, `@claws/identity` for platform authentication,
`@claws/media` for content provenance, `@claws/safety` for crisis escalation, and
`@claws/browser` for governed browser access.

|---|---|---|

This means 98.4% of the ecosystem has NO governance relationship today. claws's primary
value is establishing governance defaults for the ungoverned 98.4%.

## Key Principles

1. **Capability-based classification, not category tags**: 30% of security skills are miscategorized (breweries, Harry Potter). claws must classify by declared capabilities (file_write, network, exec) not category.

2. **OBO is the governance frontier**: 165 skills cross OBO boundaries. Every OBO action needs elicitation (who/what/when) and confirmation gates. The OBO taxonomy has 6 types: EMAIL, MESSAGE, CALENDAR, SOCIAL, PURCHASE, TRANSACT.

3. **Browser = injection surface**: All 322 browser skills are injection risk. Mandatory content sanitization via @claws/security/BrowserSanitizer.

4. **Physical world needs safety limits**: 43 IoT skills control real devices (ovens, locks, cameras). Temperature limits, auto-shutoff, camera privacy blur, lock double-confirm.

5. **Personal data needs labeling**: 100+ skills handle PHI/PII. Auto-labeling via @claws/data with HIPAA templates for health, COPPA for child data, GDPR for religious data.

6. **Budget enforcement is non-negotiable**: 111 R5 TRANSACT skills. Default daily/weekly/per-transaction limits via @claws/budget. Gambling disabled by default.

7. **Maker tools drive adoption**: Governance alone is a cost. Maker libraries (@bic/claws-test, @claws/schema, @claws/report) are value-add that makes governance easy to adopt.

## Model Evolution

- v0 (this experiment): Category-level risk defaults + OBO census + maker toolkit spec
- v1 (future): Per-skill governance profile generation from SKILL.md analysis
- v2 (future): ClawHub integration — governance badge certification for published skills
- v3 (future): Runtime enforcement via OC Gateway hooks

- **Policy templates**: Default governance profiles per skill category
- **@bic/claws-skill-kit**: Governance annotations for existing skills
- **ClawHub integration**: Governance badge / certification for skills
