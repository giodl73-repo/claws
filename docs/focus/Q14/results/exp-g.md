### Key Governance Risks

1. **Deepfake generation**: `eachlabs-face-swap`, `age-transformation`, `ai-avatar-generation`, `ai-headshot-generation` can create realistic fake images of people. **Governance: R4 + identity verification + watermark required.**
2. **Voice cloning**: `clonev` ("Clone any voice"), `eachlabs-voice-audio` (voice conversion). **Governance: R4 + consent verification.**
3. **IP/copyright**: Image generation skills (`fal-ai`, `image-gen`, `openai-image-cli`) create content that may infringe. **Governance: content provenance tracking.**
4. **Data exfiltration via media**: Generated images/PDFs can encode data (steganography). **Governance: output scanning for embedded data.**
5. **Document forgery**: `ai-pdf-builder` ("AI-powered PDF generator for legal docs"), `legaldoc-ai`, `contract-generator`. **Governance: R4 + legal document disclaimer.**
6. **NSFW content**: `nsfw-detection` exists as a filter; generation skills lack NSFW guards by default.

### Content Provenance Requirements

```yaml
content-provenance-policy:
  image_generation:
    watermark: required  # invisible AI-generated watermark
    metadata: required   # EXIF/C2PA provenance data
    deepfake_check: true # flag face-swap/age-transform outputs
    
  voice_generation:
    consent: required    # voice owner must consent
    watermark: required  # audio watermark
    clone_audit: true    # log all voice cloning operations
    
  document_generation:
    legal_disclaimer: true  # "AI-generated document" header
    tamper_detection: true  # hash-based integrity
    
  video_generation:
    deepfake_check: true
    watermark: required
```

## Maker Angle

### @claws/report for Document Generation Skills

The 110 PDF/document skills need standardized report generation:

```typescript
import { ReportBuilder } from '@claws/report';

const report = new ReportBuilder({
  template: 'invoice-v1',
  output: 'pdf',
  provenance: {
    generator: 'my-invoice-skill',
    version: '1.0.0',
    ai_generated: true,
    disclaimer: 'This document was generated by AI'
  }
});

report.addSection('header', { company, date, number });
report.addSection('line-items', items);
const pdf = await report.build();
```

### Key Maker Recommendations

1. **Provenance library**: `@claws/media` adds C2PA provenance to all generated content
2. **Report templates**: `@claws/report` provides business document templates (invoice, contract, report)
3. **Content rating**: `@claws/media/rate` classifies generated content (SFW/NSFW/violent)
4. **Voice consent**: `@claws/identity/voiceConsent` verification before cloning
5. **Deepfake detection**: `@claws/media/detectDeepfake` scans face-manipulated content
