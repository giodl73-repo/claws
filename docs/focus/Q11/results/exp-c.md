# Experiment c: Generated Skill Examples (OC-Idiomatic)

**Question**: Q12k -- What Craftworks runtime powers claws-generated skills?
**Method**: Design analysis
**Date**: 2026-04-11

---

## Design Constraint

Every generated file must pass the OC developer test: "Would an OC developer reading
this code understand it without knowing Craftworks exists?"

Generated code imports from:
- **@openclaw/\*** -- contributed OC-native packages (Tier 1)
- **@claws/runtime** -- thin governance helper functions (Tier 2)
- **OC Gateway APIs** -- standard OC skill/hook/plugin patterns

Generated code never imports from @craftworks/*.

## Example 1: Governance Guard Skill

**Source**: Generated by `claws build` from a CREST workspace with SOC 2 policy template.
**Purpose**: The primary enforcement skill. Intercepts every tool call, classifies risk,
enforces HITL gates, checks A2A depth, records audit events, and recovers from crashes.

### Generated File: `.glint/skills/governance-guard.ts`

```typescript
/**
 * Governance Guard Skill
 *
 * Auto-generated by claws build v1.0.0
 * Source: glint.json (soc2 template)
 * Compiled: 2026-04-11T09:00:00Z
 *
 * DO NOT EDIT -- regenerate with `claws build`
 */

import { AuditChain } from '@openclaw/audit-chain';
import { BudgetMeter } from '@openclaw/budget-meter';
import { IdentityBridge } from '@openclaw/identity-bridge';
import {
  classify,
  elicit,
  audit,
  checkA2A,
  checkBudget,
  evaluatePolicy,
  type CompiledRule,
  type CompiledPolicy,
  type PolicyContext,
} from '@claws/runtime';

// ── Pre-compiled policy rules (from RELAX expressions in glint.json) ──

const RULES: CompiledRule[] = [
  // From: tool.name matches "bash" → risk 5, require OBO
  { pattern: 'bash', risk: 5, obo: true, justification: 'Shell access requires human approval' },

  // From: tool.name matches "write_file" and workspace.tier < 3 → risk 4, require OBO
  { pattern: 'write_file', risk: 4, obo: true, justification: 'File writes in T1/T2 require approval' },

  // From: tool.name matches "read_file" → risk 2
  { pattern: 'read_file', risk: 2, obo: false, justification: 'Read-only filesystem access' },

  // From: tool.name matches "web_search" → risk 1
  { pattern: 'web_search', risk: 1, obo: false, justification: 'Information retrieval' },

  // Default: unclassified tools get risk 3
  { pattern: '*', risk: 3, obo: false, justification: 'Unclassified tool -- default risk' },
];

const POLICY: CompiledPolicy = {
  rules: RULES,
  version: '1.0.0',
  compiledAt: '2026-04-11T09:00:00Z',
};

// ── A2A delegation limits (from glint.json a2a.maxDepth) ──

const A2A_MAX_DEPTH = 3;

// ── Budget limits (from glint.json budget) ──

const BUDGET_CONFIG = {
  maxTokens: 500_000,
  maxCalls: 2_000,
  maxDuration: 600_000, // 10 minutes
};

// ── Skill state (initialized once per Gateway session) ──

let auditChain: AuditChain;
let budgetMeter: BudgetMeter;

async function ensureInitialized(): Promise<void> {
  if (!auditChain) {
    auditChain = AuditChain.open('.glint/audit/chain.jsonl');
  }
  if (!budgetMeter) {
    budgetMeter = BudgetMeter.create(BUDGET_CONFIG);
  }
}

// ── OC Skill Definition ──

export default {
  name: 'claws-governance-guard',
  description: 'Enforces workspace governance policies on every tool call',
  version: '1.0.0',

  /**
   * Called before every tool invocation in the OC Gateway.
   * Returns allow/deny/escalate decision.
   */
  async onToolCall(
    tool: { name: string; args: Record<string, unknown> },
    context: {
      user: { id: string };
      agent?: { id: string; delegationDepth?: number };
      session: { id: string };
    },
  ): Promise<{ action: 'allow' | 'deny'; reason?: string }> {
    await ensureInitialized();

    const operator = IdentityBridge.resolve(context);

    // Step 1: Budget check -- fail fast if budget exceeded
    const budgetResult = checkBudget(budgetMeter, { tokens: 1000, calls: 1 });
    if (!budgetResult.ok) {
      await audit(auditChain, {
        tool: tool.name,
        risk: 0,
        decision: 'deny',
        operator: operator.id,
        reason: `Budget ${budgetResult.code}: ${budgetResult.message}`,
      });
      return { action: 'deny', reason: budgetResult.message };
    }

    // Step 2: A2A depth check -- prevent unbounded delegation chains
    if (context.agent?.delegationDepth !== undefined) {
      const a2aResult = checkA2A(context.agent.delegationDepth, A2A_MAX_DEPTH);
      if (!a2aResult.allowed) {
        await audit(auditChain, {
          tool: tool.name,
          risk: 0,
          decision: 'deny',
          operator: operator.id,
          reason: `A2A depth ${a2aResult.currentDepth} exceeds max ${a2aResult.maxDepth}`,
          a2aDepth: a2aResult.currentDepth,
        });
        return {
          action: 'deny',
          reason: `Agent delegation depth ${a2aResult.currentDepth} exceeds limit of ${a2aResult.maxDepth}`,
        };
      }
    }

    // Step 3: Classify tool risk
    const policyContext: PolicyContext = {
      tool,
      workspace: { tier: 2, tags: ['soc2', 'production'] },
      operator: { id: operator.id, tier: operator.tier ?? 'developer' },
      a2a: context.agent?.delegationDepth !== undefined
        ? { depth: context.agent.delegationDepth, maxDepth: A2A_MAX_DEPTH }
        : undefined,
    };

    const policyResult = evaluatePolicy(POLICY, policyContext);

    // Step 4: If policy says escalate, run HITL elicitation
    if (policyResult.decision === 'escalate' || policyResult.decision === 'deny') {
      const classification = classify(tool.name, policyContext, RULES);

      if (classification.obo) {
        // Request human approval via OC Gateway's approval flow
        const approval = await elicit(
          { id: operator.id, channel: 'oc-gateway' },
          { name: tool.name, args: tool.args, risk: classification.risk, justification: classification.justification },
          { timeoutMs: 60_000, fallback: 'deny', reason: classification.justification },
        );

        if (!approval.approved) {
          await audit(auditChain, {
            tool: tool.name,
            risk: classification.risk,
            decision: 'deny',
            operator: operator.id,
            reason: approval.timeout
              ? 'Approval timed out (fail-closed)'
              : 'User denied tool invocation',
            policyRule: classification.matchedRule?.pattern,
          });
          return {
            action: 'deny',
            reason: approval.timeout
              ? `Approval timed out for ${tool.name} (risk ${classification.risk})`
              : `User denied ${tool.name}`,
          };
        }
      } else if (policyResult.decision === 'deny') {
        // Hard deny -- no OBO path
        await audit(auditChain, {
          tool: tool.name,
          risk: classification.risk,
          decision: 'deny',
          operator: operator.id,
          reason: 'Policy hard deny',
          policyRule: classification.matchedRule?.pattern,
        });
        return { action: 'deny', reason: `Policy denies ${tool.name}` };
      }
    }

    // Step 5: Record budget usage
    budgetMeter.record({ tokens: 1000, calls: 1 });

    // Step 6: Audit the allow decision
    const classification = classify(tool.name, policyContext, RULES);
    await audit(auditChain, {
      tool: tool.name,
      risk: classification.risk,
      decision: 'allow',
      operator: operator.id,
      policyRule: classification.matchedRule?.pattern,
    });

    return { action: 'allow' };
  },

  /**
   * Called after tool execution completes. Records actual token usage.
   */
  async onToolResult(
    tool: { name: string },
    result: { tokens_used?: number; duration_ms?: number },
  ): Promise<void> {
    await ensureInitialized();

    if (result.tokens_used || result.duration_ms) {
      budgetMeter.record({
        tokens: result.tokens_used ?? 0,
        calls: 0,
        duration: result.duration_ms ?? 0,
      });
    }
  },

  /**
   * Called on Gateway shutdown. Verifies audit chain integrity.
   */
  async onShutdown(): Promise<void> {
    if (auditChain) {
      const verification = await auditChain.verify();
      if (!verification.valid) {
        console.error(
          `[claws] Audit chain integrity check failed: ${verification.breaks.length} breaks detected`,
        );
      }
    }
  },
};
```

### What Craftworks powers (invisible to the developer)

| Generated code | Powered by | Why invisible |
|---------------|-----------|---------------|
| `RULES` array | RELAX expressions compiled to static rules | Compiler emits rule table, no RELAX at runtime |
| `classify()` | RELAX evaluator + scope resolver | Thin function wrapping glob match |
| `elicit()` | Intervention ladder (L0-L5) | Wraps OC exec-approvals API |
| `checkA2A()` | DelegationGuard (createDelegationContext) | Returns plain `{ allowed, depth }` object |
| `checkBudget()` | GovernanceManager 80/95/100% thresholds | Returns plain `{ ok, code }` object |
| `AuditChain.append()` | suite/audit hash chain + WAL | OC-native @openclaw/ package |
| `BudgetMeter.create()` | GovernanceManager constructor | OC-native @openclaw/ package |

## Example 2: Custom Business Skill

**Source**: Generated by `claws build` from a SKILL.md specification file.
**Purpose**: Demonstrates that claws generates ANY skill, not just governance guards.
This is a customer support skill that queries a knowledge base, validates output
quality, and logs to the compliance audit trail.

### Source: `skills/customer-lookup.md`

```markdown
---
name: customer-lookup
tier: L2
description: Look up customer information from the knowledge base
inputs:
  - query: string
outputs:
  - summary: string
  - confidence: number
quality:
  - no_pii_in_summary: true
  - min_confidence: 0.7
audit: true
---

# Customer Lookup Skill

Searches the customer knowledge base and returns a summary.
Output must not contain PII (names, emails, phone numbers).
```

### Generated File: `.glint/skills/customer-lookup.ts`

```typescript
/**
 * Customer Lookup Skill
 *
 * Auto-generated by claws build v1.0.0
 * Source: skills/customer-lookup.md
 * Compiled: 2026-04-11T09:00:00Z
 *
 * DO NOT EDIT -- regenerate with `claws build`
 */

import { AuditChain } from '@openclaw/audit-chain';
import { SecretScanner } from '@openclaw/secret-scanner';
import { audit } from '@claws/runtime';

// ── Quality gate patterns (compiled from skill spec quality rules) ──

const PII_PATTERNS = [
  /\b\d{3}-\d{2}-\d{4}\b/,                        // SSN
  /\b\d{16}\b/,                                     // Credit card
  /\b[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}\b/i,   // Email
  /\b\(\d{3}\)\s?\d{3}-\d{4}\b/,                    // Phone (US)
  /\b\d{3}\.\d{3}\.\d{4}\b/,                        // Phone (dotted)
];

const MIN_CONFIDENCE = 0.7;

// ── Skill state ──

let auditChain: AuditChain;
let secretScanner: SecretScanner;

async function ensureInitialized(): Promise<void> {
  if (!auditChain) {
    auditChain = AuditChain.open('.glint/audit/chain.jsonl');
  }
  if (!secretScanner) {
    secretScanner = SecretScanner.create({
      patterns: ['ssn', 'credit_card', 'email', 'phone'],
    });
  }
}

// ── Quality validation ──

function containsPII(text: string): boolean {
  return PII_PATTERNS.some(pattern => pattern.test(text));
}

function validateOutput(
  summary: string,
  confidence: number,
): { valid: boolean; reasons: string[] } {
  const reasons: string[] = [];

  if (containsPII(summary)) {
    reasons.push('Summary contains PII -- must be redacted before returning');
  }

  if (confidence < MIN_CONFIDENCE) {
    reasons.push(
      `Confidence ${confidence.toFixed(2)} below minimum ${MIN_CONFIDENCE}`,
    );
  }

  return { valid: reasons.length === 0, reasons };
}

// ── OC Skill Definition ──

export default {
  name: 'customer-lookup',
  description: 'Look up customer information from the knowledge base',
  version: '1.0.0',

  /**
   * Main skill handler. Called when the agent invokes the customer-lookup tool.
   */
  async execute(
    input: { query: string },
    context: {
      user: { id: string };
      model: { complete: (opts: { prompt: string; max_tokens: number }) => Promise<{ text: string }> };
      data: { query: (collection: string, filter: Record<string, unknown>) => Promise<unknown[]> };
    },
  ): Promise<{ summary: string; confidence: number }> {
    await ensureInitialized();

    // Step 1: Query the knowledge base (OC data API)
    const results = await context.data.query('customers', {
      search: input.query,
      limit: 5,
    });

    if (results.length === 0) {
      await audit(auditChain, {
        tool: 'customer-lookup',
        risk: 1,
        decision: 'allow',
        operator: context.user.id,
        reason: 'No results found',
      });

      return { summary: 'No matching customers found.', confidence: 1.0 };
    }

    // Step 2: Generate summary using the Gateway's model (OC model API)
    const prompt = [
      'Summarize the following customer records. Do NOT include names, emails,',
      'phone numbers, or any personally identifiable information.',
      '',
      'Records:',
      JSON.stringify(results, null, 2),
      '',
      'Provide a factual summary focused on account status and history.',
    ].join('\n');

    const response = await context.model.complete({
      prompt,
      max_tokens: 500,
    });

    const summary = response.text;
    const confidence = results.length >= 3 ? 0.9 : results.length >= 1 ? 0.75 : 0.5;

    // Step 3: Quality gate -- PII check
    const validation = validateOutput(summary, confidence);

    if (!validation.valid) {
      // Redact PII if found, log the violation
      const safeSummary = secretScanner.redact(summary);

      await audit(auditChain, {
        tool: 'customer-lookup',
        risk: 3,
        decision: 'allow',
        operator: context.user.id,
        reason: `Quality gate triggered: ${validation.reasons.join('; ')}. Output redacted.`,
      });

      return { summary: safeSummary, confidence };
    }

    // Step 4: Audit the successful lookup
    await audit(auditChain, {
      tool: 'customer-lookup',
      risk: 1,
      decision: 'allow',
      operator: context.user.id,
      reason: 'Lookup completed, quality gates passed',
    });

    return { summary, confidence };
  },
};
```

### What Craftworks powers (invisible to the developer)

| Generated code | Powered by | Why invisible |
|---------------|-----------|---------------|
| `PII_PATTERNS` array | Eval framework L0 assertions (compiled to regex) | Compiler extracts patterns from quality spec |
| `MIN_CONFIDENCE` | Eval rubric criterion (compiled to constant) | Compiler reads quality threshold from spec |
| `SecretScanner.redact()` | agent-sdk/hashing + pattern detection | OC-native @openclaw/ package |
| `AuditChain.append()` | suite/audit hash chain | OC-native @openclaw/ package |
| `audit()` | GovernanceEvent → AuditEvent mapping | Thin @claws/runtime helper |
| `context.model.complete()` | OC Gateway model API | Native OC pattern, not Craftworks |
| `context.data.query()` | OC Gateway data API | Native OC pattern, not Craftworks |

## Example 3: Fleet Scan Skill

**Source**: Generated by `claws build` for fleet-wide governance scanning.
**Purpose**: Discovers all agent workspaces, checks each for policy compliance,
detects drift from baseline, and produces a fleet-wide report. Runs as
`claws scan` or `claws drift`.

### Generated File: `.glint/skills/fleet-scan.ts`

```typescript
/**
 * Fleet Scan Skill
 *
 * Auto-generated by claws build v1.0.0
 * Source: glint.json (fleet configuration)
 * Compiled: 2026-04-11T09:00:00Z
 *
 * DO NOT EDIT -- regenerate with `claws build`
 */

import { AuditChain } from '@openclaw/audit-chain';
import { SiemEmitter } from '@openclaw/siem-emitter';
import { audit, drift, evaluatePolicy, type CompiledPolicy } from '@claws/runtime';
import { readdir, readFile, stat } from 'node:fs/promises';
import { join, resolve } from 'node:path';

// ── Fleet configuration (from glint.json fleet section) ──

const SCAN_ROOTS = [
  '/workspaces',
  '/home/*/agents',
];

const WORKSPACE_MARKERS = [
  'SOUL.md',          // OpenClaw
  '.cursorrules',     // Cursor
  'CLAUDE.md',        // Claude Code
  '.github/copilot-instructions.md', // GitHub Copilot
  'glint.json',       // claws-managed
];

const CONCURRENCY_LIMIT = 10;

const BASELINE_PATH = '.glint/cache/snapshots/fleet-baseline.json';

// ── Fleet policy (compiled from fleet-level RELAX expressions) ──

const FLEET_POLICY: CompiledPolicy = {
  rules: [
    { pattern: 'bash', risk: 5, obo: true, justification: 'Shell access requires approval' },
    { pattern: 'write_file', risk: 4, obo: true, justification: 'File writes require approval in fleet' },
    { pattern: '*', risk: 2, obo: false, justification: 'Fleet default' },
  ],
  version: '1.0.0',
  compiledAt: '2026-04-11T09:00:00Z',
};

// ── Types ──

interface DiscoveredWorkspace {
  path: string;
  platform: string;
  hasGlintConfig: boolean;
}

interface ScanFinding {
  workspace: string;
  severity: 'critical' | 'high' | 'medium' | 'low' | 'info';
  message: string;
  rule?: string;
}

interface DriftFinding {
  workspace: string;
  changes: Array<{ path: string; type: 'added' | 'removed' | 'modified' }>;
}

interface FleetScanResult {
  scannedAt: string;
  workspacesFound: number;
  workspacesScanned: number;
  findings: ScanFinding[];
  driftFindings: DriftFinding[];
  summary: {
    compliant: number;
    violations: number;
    drifted: number;
  };
}

// ── Workspace discovery ──

async function discoverWorkspaces(roots: string[]): Promise<DiscoveredWorkspace[]> {
  const workspaces: DiscoveredWorkspace[] = [];

  for (const root of roots) {
    const expandedRoot = resolve(root);
    let entries: string[];
    try {
      entries = await readdir(expandedRoot);
    } catch {
      continue; // Root doesn't exist -- skip
    }

    for (const entry of entries) {
      const entryPath = join(expandedRoot, entry);
      const entryStat = await stat(entryPath).catch(() => null);
      if (!entryStat?.isDirectory()) continue;

      // Check for workspace markers
      for (const marker of WORKSPACE_MARKERS) {
        const markerPath = join(entryPath, marker);
        const exists = await stat(markerPath).then(() => true).catch(() => false);
        if (exists) {
          const platform = detectPlatform(marker);
          const hasGlintConfig = await stat(join(entryPath, 'glint.json'))
            .then(() => true)
            .catch(() => false);

          workspaces.push({ path: entryPath, platform, hasGlintConfig });
          break; // Found a marker, don't check the rest
        }
      }
    }
  }

  return workspaces;
}

function detectPlatform(marker: string): string {
  const platforms: Record<string, string> = {
    'SOUL.md': 'openclaw',
    '.cursorrules': 'cursor',
    'CLAUDE.md': 'claude',
    '.github/copilot-instructions.md': 'github-copilot',
    'glint.json': 'claws-managed',
  };
  return platforms[marker] ?? 'unknown';
}

// ── Policy scanning ──

async function scanWorkspace(workspace: DiscoveredWorkspace): Promise<ScanFinding[]> {
  const findings: ScanFinding[] = [];

  // Check 1: Does the workspace have a glint.json?
  if (!workspace.hasGlintConfig) {
    findings.push({
      workspace: workspace.path,
      severity: 'high',
      message: 'No glint.json found -- workspace is ungoverned',
    });
    return findings; // Can't check further without config
  }

  // Check 2: Load workspace config and evaluate policies
  try {
    const configRaw = await readFile(join(workspace.path, 'glint.json'), 'utf-8');
    const config = JSON.parse(configRaw);

    // Validate required fields
    if (!config.version) {
      findings.push({
        workspace: workspace.path,
        severity: 'medium',
        message: 'glint.json missing version field',
        rule: 'G-CONFIG-VERSION',
      });
    }

    if (!config.policies || config.policies.length === 0) {
      findings.push({
        workspace: workspace.path,
        severity: 'high',
        message: 'No policies configured in glint.json',
        rule: 'G-POLICY-REQUIRED',
      });
    }

    // Check 3: Verify audit chain integrity
    const auditPath = join(workspace.path, '.glint', 'audit', 'chain.jsonl');
    const auditExists = await stat(auditPath).then(() => true).catch(() => false);

    if (auditExists) {
      const chain = AuditChain.open(auditPath);
      const verification = await chain.verify();

      if (!verification.valid) {
        findings.push({
          workspace: workspace.path,
          severity: 'critical',
          message: `Audit chain integrity failure: ${verification.breaks.length} breaks`,
          rule: 'G-AUDIT-INTEGRITY',
        });
      }
    } else {
      findings.push({
        workspace: workspace.path,
        severity: 'medium',
        message: 'No audit chain found',
        rule: 'G-AUDIT-REQUIRED',
      });
    }
  } catch (err) {
    findings.push({
      workspace: workspace.path,
      severity: 'high',
      message: `Failed to read glint.json: ${(err as Error).message}`,
      rule: 'G-CONFIG-VALID',
    });
  }

  return findings;
}

// ── Drift detection ──

async function detectDrift(
  workspace: DiscoveredWorkspace,
  baseline: Record<string, unknown>,
): Promise<DriftFinding | null> {
  try {
    const configRaw = await readFile(join(workspace.path, 'glint.json'), 'utf-8');
    const currentConfig = JSON.parse(configRaw);

    const workspaceBaseline = baseline[workspace.path] as Record<string, unknown> | undefined;
    if (!workspaceBaseline) {
      return null; // No baseline for this workspace -- skip drift check
    }

    const driftReport = drift(currentConfig, workspaceBaseline);

    if (driftReport.drifted) {
      return {
        workspace: workspace.path,
        changes: driftReport.changes,
      };
    }
  } catch {
    // Can't read config -- already reported by scanWorkspace
  }

  return null;
}

// ── Parallel execution with concurrency limit ──

async function runWithConcurrency<T, R>(
  items: T[],
  limit: number,
  fn: (item: T) => Promise<R>,
): Promise<R[]> {
  const results: R[] = [];
  const executing: Promise<void>[] = [];

  for (const item of items) {
    const promise = fn(item).then(result => {
      results.push(result);
    });
    executing.push(promise);

    if (executing.length >= limit) {
      await Promise.race(executing);
      // Remove settled promises
      for (let i = executing.length - 1; i >= 0; i--) {
        const settled = await Promise.race([
          executing[i]!.then(() => true),
          Promise.resolve(false),
        ]);
        if (settled) executing.splice(i, 1);
      }
    }
  }

  await Promise.all(executing);
  return results;
}

// ── OC Skill Definition ──

export default {
  name: 'claws-fleet-scan',
  description: 'Discover and scan all agent workspaces for governance compliance',
  version: '1.0.0',

  /**
   * Main scan handler. Called by `claws scan` or `claws pinch --fleet`.
   */
  async execute(
    input: {
      mode: 'scan' | 'drift' | 'full';
      roots?: string[];
      format?: 'json' | 'sarif' | 'table';
    },
    context: {
      user: { id: string };
    },
  ): Promise<FleetScanResult> {
    const roots = input.roots ?? SCAN_ROOTS;
    const auditChain = AuditChain.open('.glint/audit/fleet-chain.jsonl');

    // Step 1: Discover workspaces
    const workspaces = await discoverWorkspaces(roots);

    await audit(auditChain, {
      tool: 'fleet-scan',
      risk: 1,
      decision: 'allow',
      operator: context.user.id,
      reason: `Discovered ${workspaces.length} workspaces`,
    });

    // Step 2: Scan workspaces for policy compliance (with concurrency limit)
    const allFindings: ScanFinding[] = [];

    if (input.mode === 'scan' || input.mode === 'full') {
      const scanResults = await runWithConcurrency(
        workspaces,
        CONCURRENCY_LIMIT,
        scanWorkspace,
      );
      for (const findings of scanResults) {
        allFindings.push(...findings);
      }
    }

    // Step 3: Detect drift from baseline
    const driftFindings: DriftFinding[] = [];

    if (input.mode === 'drift' || input.mode === 'full') {
      let baseline: Record<string, unknown> = {};
      try {
        const baselineRaw = await readFile(BASELINE_PATH, 'utf-8');
        baseline = JSON.parse(baselineRaw);
      } catch {
        // No baseline -- skip drift detection
      }

      const driftResults = await runWithConcurrency(
        workspaces,
        CONCURRENCY_LIMIT,
        (ws) => detectDrift(ws, baseline),
      );

      for (const finding of driftResults) {
        if (finding) driftFindings.push(finding);
      }
    }

    // Step 4: Compute summary
    const compliantCount = workspaces.length -
      new Set(allFindings.filter(f => f.severity !== 'info').map(f => f.workspace)).size;

    const result: FleetScanResult = {
      scannedAt: new Date().toISOString(),
      workspacesFound: workspaces.length,
      workspacesScanned: workspaces.length,
      findings: allFindings,
      driftFindings,
      summary: {
        compliant: compliantCount,
        violations: allFindings.filter(f => f.severity === 'critical' || f.severity === 'high').length,
        drifted: driftFindings.length,
      },
    };

    // Step 5: Audit the fleet scan completion
    await audit(auditChain, {
      tool: 'fleet-scan',
      risk: 1,
      decision: 'allow',
      operator: context.user.id,
      reason: `Fleet scan complete: ${result.summary.compliant}/${workspaces.length} compliant, ${result.summary.violations} violations, ${result.summary.drifted} drifted`,
    });

    // Step 6: Export to SIEM if configured
    if (allFindings.length > 0) {
      const emitter = SiemEmitter.create({ format: 'sarif', destination: 'stdout' });
      for (const finding of allFindings) {
        await emitter.emit({
          action: 'fleet.finding',
          target: finding.workspace,
          severity: finding.severity,
          reason: finding.message,
        });
      }
    }

    return result;
  },
};
```

### The OC Developer Test

An OC developer reading any of these three skills would see:
- Standard OC skill patterns (onToolCall, execute, onShutdown)
- Familiar npm packages (@openclaw/audit-chain, etc.)
- Plain TypeScript (no monads, no FSMs, no IRs)
- Simple data structures (arrays, objects, strings)
- Standard async/await patterns
- No unfamiliar abstractions

They would NOT see:
- WorkAgentSupervisor
- TaskFsm with 11-state lifecycle
- RELAX expressions or type system
- DataFrames or MaterializationRegistry
- DelegationContext or ScopeType
- Result<T> monads or error codes

The Craftworks quality (hash-chained audit, budget thresholds, delegation depth limits,
type-checked policies) is present in every skill. But the Craftworks machinery is invisible.
