# @bic/claws

The claws CLI — the binary operators invoke to init workspaces, run
doctor, manage snapshots, and drive enterprise governance. Thin
UI adapter over `claws-sdk`.

## Two-letter code

**CX** — package primary. Sub-specs: **CXS** (command surface),
**CXJ** (claws.json config), **CXP** (platform detection).

## Stability

- **Stability tier**: Alpha
- **Upstream target**: none (internal CLI)
