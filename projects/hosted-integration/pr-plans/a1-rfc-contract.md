# A1: Hosted Integration RFC Contract

## Outcome

Submit the accepted Hosted Integration and Capability Bindings contract to
`openclaw/rfcs`.

## Repository And Dependencies

- Repository: `openclaw/rfcs`
- Depends on: architecture approval

## Change

- Define the four areas, ownership rule, and central bundle registration.
- Specify typed owner references, Hosting Profiles, Status, and Doctor.
- Define the one-hop provider dispatcher and narrow reverse carrier.
- Record the full CAPI vertical as the first implementation milestone.
- Keep local bindings and native Gateway/Channel paths first-class.

## Non-Goals

- No implementation API names beyond contract-level identifiers.
- No generic bus, callback registry, or ProxyPipe wire standardization.

## Proof And Exit

- Maintainer review accepts ownership, security, migration, and V1 boundaries.
- All unresolved questions are either closed or assigned to a named later PR.
- The RFC links the implementation series and conformance expectations.
