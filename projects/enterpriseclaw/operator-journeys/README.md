# EnterpriseClaw Operator Journeys

These journeys prove that the thirty-five contract scopes can produce a simple,
truthful human experience.

Each journey has four layers:

1. the human question and available action;
2. the product projection shown by CLI or Control UI;
3. the retained EC contracts that make the projection truthful; and
4. accepted and structured-failure fixtures for conformance.

The journey does not replace or merge RFC scopes. It composes them.

## Golden Journeys

| Journey | Status | Primary proof target |
| --- | --- | --- |
| Protected external effect | Designed, role-reviewed, and simulated | Approval remains bound to dispatch and timeout does not authorize blind retry |
| Durable conversation and delivery | Designed, role-reviewed, and simulated | Restart, fenced attempts, late/partial receipts, export, deletion, and retained-copy truth |
| Fleet rollout and recovery | Designed, role-reviewed, and simulated | Immutable target set, partial failure, targeted repair, restore fencing, assurance separation, and containment truth |
