@steipete following your Tauri suggestion, we extracted [openclaw-gateway-client](https://github.com/openclaw/openclaw/pull/116050), built a shared [Rust node runtime](https://github.com/openclaw/openclaw/pull/116450), and added its [authenticated sidecar contract](https://github.com/openclaw/openclaw/pull/116863). The first adopter would be the Copilot app system tray in Edge/Chromium, manageable through the Gateway by Scout Cloud, Cowork, and other authorized controllers.

@shanselman wants Windows Companion and the [Windows node](https://github.com/openclaw/openclaw-windows-node/pull/1068) aligned on the same crates to simplify that stack. [RFC 0028](https://github.com/openclaw/rfcs/pull/54) ties the proposal together while leaving production IPC and rollout as explicit follow-ups.
