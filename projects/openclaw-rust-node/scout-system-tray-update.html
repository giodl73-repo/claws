Scout system-app tray: OpenClaw Rust runtime proposal

Here is what I am filing following Peter’s Tauri refactor suggestion:

  • openclaw-gateway-client extracts the reusable Rust Gateway connection layer.
  • openclaw-node-host adds the shared Rust node runtime.
  • Authenticated sidecar bridge defines the product-neutral host/runtime contract.
  • Windows-node integration proves the Windows seam while retaining C# as the production default.

The first adopter would be the Copilot app system tray in Edge/Chromium, making it an OpenClaw node manageable through the Gateway by Scout Cloud, Cowork, and other authorized controllers.

Incremental adoption: we can take drops of these crates as each layer merges, integrate them behind the tray boundary, and provide feedback early—without waiting for the entire production IPC and rollout stack.

RFC 0028 ties together ownership, the implementation series, the Windows proof, and the remaining production gates.
