# Module 10 Private Source Audit

This is private operating context. Do not copy private provenance, names,
levels, employers, promotion machinery, assessments, or identifying examples
into LIFT.

## Source concepts reviewed

- personal score tracking;
- self-assessment guides;
- score history;
- action plans and review cadence;
- dashboards and status summaries;
- assessment schemas;
- generated recommendations;
- the accepted public records in Modules 00-09.

## Retain through rewrite

- a dated evidence snapshot;
- evidence and counterevidence before score;
- explicit uncertainty and confidence;
- one next question or bounded experiment;
- event-based review;
- historical snapshots rather than overwritten history;
- commitments with owners and disposition;
- lightweight plain-text records;
- user control over private reflection.

## Remove

- names, employer, team, level, or other identifiers as required fields;
- M/S/E sums, averages, patterns, gradients, and promotion gates;
- promotion readiness, probability, or timeline;
- automatic stay, transfer, or exit recommendations;
- universal 90-day plans;
- score correction arithmetic;
- centralized dashboards and team comparison;
- reusable candidate or employee assessment schemas;
- generated career recommendations;
- automatic reminders, inference, scraping, or AI scoring;
- filled personal records in source control;
- software before repeated independent use proves a need.

## Public rewrite thesis

The module records in LIFT already work. A public operating toolkit should
compose them into a small private-first workflow and delete duplication without
creating a platform.

The public toolkit should:

- provide plain Markdown templates;
- let the user choose only the record needed;
- keep filled records private by default;
- separate private reflection from a minimal shared conversation record;
- use events and decisions as review triggers;
- preserve history through dated snapshots;
- define archive and deletion conditions;
- prevent cross-person comparison;
- include the ethical-use gate in every shared workflow;
- state clear software admission gates.

## External comparison

- personal journals preserve user control but often lack evidence discipline:
  adapt;
- task trackers support action and closure but can turn reflection into activity
  counts: adapt cautiously;
- performance-management and talent systems centralize comparison and
  employment decisions: avoid;
- personal relationship-management systems can encourage surveillance and
  relationship optimization: avoid;
- plain Markdown is portable and inspectable but does not provide encryption,
  access control, or deletion proof: use only in an appropriate private storage
  location.

No external source establishes that maintaining a LIFT record improves career
outcomes.
