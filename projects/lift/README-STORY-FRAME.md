# LIFT README Story Frame

This is private coordination context for the public repository front door.

## Working owner system

- Modules 00-10 define the framework.
- Reader guides route common questions.
- The toolkit provides blank private-first records.
- Root policies govern evidence, ethical use, and publication.
- Role reviews and independent review provide assurance and learning.

## Missing shared capability

The root README links these surfaces but does not yet explain one coherent
reader journey.

## Story thesis

Good work does not automatically become shared organizational evidence.
Context, credit, resources, opportunity, and advocacy travel through people and
pathways that may be healthy, delayed, distorted, concentrated, unequal, or
unknown.

LIFT helps a person:

```text
Observe
  -> assess
  -> map
  -> act
  -> reassess
```

Safety and ethical use constrain every step.

## Deletion target

Remove the front-door experience of:

- eleven modules as a required linear curriculum;
- a fifteen-step start list;
- a maturity inventory that dominates the conclusion;
- model vocabulary before the human problem;
- no clear route for someone who has one immediate question.

## V1 front door

- human problem and non-claim;
- M/S/E model;
- operating arc;
- audience and allowed uses;
- route by reader need;
- grouped module journey;
- safety boundary;
- concise maturity and public-good statement.

## Disproof

The rewrite fails if a first-time reader cannot answer:

- Is LIFT for me?
- What problem does it help inspect?
- What should I read or copy first?
- What does an M/S/E profile mean?
- What must LIFT never be used for?
- What remains unvalidated?
