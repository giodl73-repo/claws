   native PTY execution relies on a beta fork with one npm maintainer.
2. `@aws-sdk/core@3.977.1`: deprecated transitive R3 runtime across core,
   Bedrock, memory, and other shipped paths; a newer version is available.
3. `audio-decode@2.2.3`: direct optional WhatsApp dependency renamed to
   `@audio/decode`.
4. `crypto-js@4.2.0`: unmaintained optional ZaloUser transitive dependency.
5. `js-yaml@4.3.0`: exact OSV record, currently classified as root build/dev
   reach rather than shipped runtime.

The baseline root production `pnpm audit --json --prod` reports zero
advisories across 1,293 dependencies. The broader OSV scan still finds the
items above because it covers exact lock records, optional paths, release
tools, and non-npm ecosystems.

### Linux desktop Cargo lock

Seventeen records in `apps/linux/src-tauri/Cargo.lock` have RustSec or GHSA
records. Reverse dependency tracing confirmed that the GTK3 and `unic-*`
clusters enter through Tauri, WebKitGTK, and `urlpattern`. `gtk3-macros` and
`proc-macro-error` are build-time only and are now Moderate/R1. The other 15
remain High/R3 pending a maintained Linux-stack migration or time-bounded risk
acceptance.

### Release tooling

Fourteen reviewed rows are isolated to checked-in ClawHub/Vercel release
`package-lock.json` files. The scanner previously overstated flattened lock
entries as direct; only `vercel` and `clawhub` are root declarations. Nine
findings are Moderate/R1. `sandbox`, `tar`, and three `undici` versions remain
High/R1 and should be removed through parent lock refreshes rather than direct
OpenClaw overrides.
