# PR Queues

Use this directory for cross-project PR queue notes. Keep the live source of
truth in GitHub, but use this area for local operator summaries that connect
OpenClaw, Lobster, RFCs, proof, and review-bot state.

Start watcher sessions from `SESSION.md`. That file defines the staleness,
proof, ClawSweeper, Gitcrawl, and branch-hygiene loop.

Suggested note shape:

```text
PR:
Repo:
Branch:
Local worktree:
Current SHA:
Status:
Blockers:
Next action:
Proof:
Review signals:
```
